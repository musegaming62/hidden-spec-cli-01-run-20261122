# Build mend, one patch tool for every AI edit format

mend is a command-line tool that reads a patch in one of four formats (unified diff, SEARCH/REPLACE blocks, V4A, JSON edits), finds the lines each edit names, and writes every change or none — for the make.fun competition [hidden-spec-cli-01-run-20261122](https://make.fun/bounty/hidden-spec-cli-01-run-20261122).

Implemented as `main.ts` (Node 22, standard library only), run as `node main.ts [options] [PATCH]`.
